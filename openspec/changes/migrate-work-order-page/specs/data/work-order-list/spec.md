# Spec Delta

## Purpose

提供工单列表数据能力：按日期与状态筛选获取工单列表（分页）、当月日历计数与未完结日期标记、风险标签色配置的读取与映射。支撑工单列表页（契约见 `ui/work-order-list`）。

## ADDED Requirements

### Requirement: 日工单获取与筛选

系统 SHALL 按所选工单日期与状态筛选条件向工单列表接口（`Order.Order` 域）获取工单列表。状态筛选 MUST 映射为服务端既定的状态类型取值（映射规则与原工程一致）；「全部」筛选 MUST 不携带状态过滤。列表 MUST 支持分页：以增量方式加载后续页，并与已加载条目合并去重。

#### Scenario: 按日期加载工单

- **WHEN** 以某工单日期发起加载
- **THEN** 返回该日期下的工单列表（含时间、门店/地址、风险标签、进度、状态等展示数据）

#### Scenario: 按状态筛选

- **WHEN** 选择某一状态筛选
- **THEN** 仅返回该状态类型的工单

#### Scenario: 分页加载更多

- **WHEN** 已加载首页后请求下一页
- **THEN** 新页条目追加到列表尾部，重复条目不重复呈现

#### Scenario: 请求失败可重试

- **WHEN** 列表接口调用失败
- **THEN** 返回失败原因，已加载内容不被清空

### Requirement: 日历计数标记

系统 SHALL 获取指定月份内各日的工单计数，供日历按日呈现数量标记。计数获取失败 MUST NOT 影响列表使用（日历降级为无标记）。

#### Scenario: 月计数用于日历标记

- **WHEN** 切换到某个月份
- **THEN** 该月有工单的日期在日历上呈现数量标记

### Requirement: 未完结日期标记

系统 SHALL 获取指定月份内的未完结（有待办）日期集合，供日历按日呈现未完结标记。获取失败 MUST NOT 影响列表使用。

#### Scenario: 未完结日期标记

- **WHEN** 某日期存在未完结工单
- **THEN** 该日期在日历上呈现未完结标记

### Requirement: 风险标签色配置

系统 SHALL 从 `Order.Order/initInfo` 的颜色配置（`color_config.risk_title`）读取风险标签到颜色的映射，供工单卡片风险标签着色。映射 MUST 对无法识别的颜色值安全忽略；配置缺失或获取失败时 MUST 以默认风险色呈现标签。

#### Scenario: 风险标签按配置着色

- **WHEN** 配置返回「高风险 → #RRGGBB」映射且卡片含「高风险」标签
- **THEN** 标签按配置色呈现

#### Scenario: 配置缺失时默认色

- **WHEN** 颜色配置缺失或标签无对应色值
- **THEN** 标签以默认风险色呈现
