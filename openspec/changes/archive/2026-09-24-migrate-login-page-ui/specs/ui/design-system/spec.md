# Spec Delta

## Purpose

为跨端应用提供统一的设计基础层：一组可复用的设计 token（颜色、字号、间距、控件尺寸）与通用 UI 组件（主操作按钮、主输入框、加载视图），使各业务页面在 Android / iOS / 鸿蒙 三端呈现一致、且无需重复定义视觉常量。

## ADDED Requirements

### Requirement: 设计 token 的可用性与稳定性

共享设计层 SHALL 提供集中定义的视觉常量，覆盖品牌色、文本色、背景色、边框色、遮罩色、间距、控件高度、图标尺寸与字号。业务页面 SHALL 通过引用这些常量取值，而不是在页面内散落硬编码的字面量。

#### Scenario: 页面引用 token 而非硬编码

- **WHEN** 业务页面需要品牌主色、标准控件高度或标准字号
- **THEN** 该值可从一个集中定义的 token 集合中取得
- **AND** 修改该 token 的取值能够同时影响所有引用它的页面

#### Scenario: token 在三端取值一致

- **WHEN** 同一 token 在 Android、iOS、鸿蒙 三端被读取
- **THEN** 三者解析出的数值完全相同

### Requirement: 主操作按钮

共享设计层 SHALL 提供一个主操作按钮组件，用于页面级主操作。该按钮 MUST 支持：自定义文案、点击回调、启用/禁用、加载中、自定义容器色与禁用色、自定义高度、以及位于内容末端（end）的可选图标。

#### Scenario: 默认态渲染

- **WHEN** 按钮以启用、非加载状态渲染
- **THEN** 按钮展示传入的文案与可选末端图标
- **AND** 按钮宽度撑满父容器，圆角为高度的一半（胶囊形）

#### Scenario: 禁用态不可点击

- **WHEN** 按钮处于禁用状态
- **THEN** 按钮使用传入的禁用容器色渲染
- **AND** 用户点击不触发点击回调

#### Scenario: 加载态

- **WHEN** 按钮处于加载状态
- **THEN** 文案与图标位置改为展示一个圆形进度指示器
- **AND** 按钮在加载期间不响应点击

#### Scenario: 加载中优先于启用状态

- **WHEN** 按钮同时被置为启用状态与加载状态
- **THEN** 按钮呈现加载态且不可点击

### Requirement: 主输入框

共享设计层 SHALL 提供一个主输入框组件，用于登录等主表单场景。该组件 MUST 支持：值、值变更回调、占位文案、可选前置图标与后置图标、视觉变换（用于密码遮蔽）、键盘选项、启用/禁用、自定义高度、自定义字号，以及区分聚焦/未聚焦/禁用三种状态下的边框色与容器色。

#### Scenario: 聚焦态与未聚焦态视觉区分

- **WHEN** 输入框获得焦点
- **THEN** 边框使用传入的聚焦边框色渲染
- **WHEN** 输入框失去焦点
- **THEN** 边框使用传入的未聚焦边框色渲染
- **AND** 容器色在聚焦与未聚焦时保持为传入的容器色

#### Scenario: 前置与后置图标

- **WHEN** 调用方传入前置图标和后置图标
- **THEN** 两个图标分别渲染在输入内容的起始端与末端
- **AND** 前置图标在聚焦时使用强调色、未聚焦时使用弱化色

#### Scenario: 密码遮蔽

- **WHEN** 调用方传入密码视觉变换
- **THEN** 输入内容以遮蔽符号呈现，而非明文

#### Scenario: 禁用态

- **WHEN** 输入框处于禁用状态
- **THEN** 输入框不接受输入，且文案与图标使用弱化色渲染

#### Scenario: 单行约束

- **WHEN** 输入框以单行模式渲染
- **THEN** 输入框高度固定为传入的高度，不随内容增长

### Requirement: 统一加载视图

共享设计层 SHALL 提供一个通用的加载视图，作为页面处于加载状态时的统一呈现。该视图 MUST 在父容器内居中展示一个圆形进度指示器。

#### Scenario: 加载视图居中呈现

- **WHEN** 加载视图被渲染
- **THEN** 一个圆形进度指示器出现在父容器的正中央
- **AND** 视图占据父容器的全部可用尺寸

### Requirement: 统一页面状态模型

共享设计层 SHALL 提供统一的页面状态封装，供所有业务页面使用。该状态模型 MUST 至少覆盖：空闲、加载中、成功（携带数据）、空数据、错误（携带消息与可选异常）、无权限。业务页面 MUST NOT 自定义页面级状态枚举。

#### Scenario: 成功状态携带数据

- **WHEN** 页面状态为成功
- **THEN** 该状态携带一个具体的数据对象供页面读取

#### Scenario: 错误状态携带错误信息

- **WHEN** 页面状态为错误
- **THEN** 该状态携带一条错误消息
- **AND** 可选地携带引发该错误的异常对象

#### Scenario: 无数据状态不带负载

- **WHEN** 页面状态为空数据或无权限
- **THEN** 该状态不携带任何数据负载，仅表示页面应渲染对应的占位呈现
